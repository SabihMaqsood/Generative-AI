LangChain Document Loader Practice

Welcome to LangChain Document Loader practice.

1. LangChain
LangChain is a framework for building applications powered by language models.
Document loaders are used to load data from different sources into LangChain Document objects.

2. What is a Document?
A LangChain Document normally contains:
- page_content: the actual text
- metadata: information about the source, file, page, or other details

3. TextLoader Practice
TextLoader is used to load plain text files into LangChain.

Practice:
- Load this file using TextLoader.
- Print the loaded documents.
- Print page_content.
- Print metadata.
- Check the number of documents returned.

6. Other LangChain Loaders
After practicing TextLoader, try:
- PyPDFLoader for PDF files
- CSVLoader for CSV files
- JSONLoader for JSON files
- Docx2txtLoader for DOCX files
- WebBaseLoader for web pages

Keep practicing different loaders so you understand how different data sources are converted into LangChain Documents.
